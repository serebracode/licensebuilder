# Источники данных и подготовка контента

На текущем этапе приложение работает с локальными JSON-файлами, а не напрямую с `.docx`.

## Что должно лежать в файловой системе

- `blocks/` — отдельный JSON на каждый блок прав.
- `templates/` — JSON-файлы сохранённых наборов блоков.
- `exports/` — сюда будут записываться `.docx` и `.pdf`.
- `frame.json` — общая рамка договора (`header` + `footer`).

## Как перенести ваши текущие .docx в новую модель

1. Разделите типовой договор на:
   - общую часть сверху (`header`),
   - повторяемые блоки прав,
   - общую часть снизу (`footer`).
2. Для каждого блока создайте JSON-файл формата:

```json
{
  "id": "web",
  "title": "Веб-лицензия",
  "description": "Использование на сайтах через CSS",
  "body": "Лицензиат вправе использовать Шрифт ... {{domain}}",
  "variables": ["domain"]
}
```

3. Всё, что меняется от договора к договору, замените переменными `{{variable_name}}`.
4. `frame.json` оформите так:

```json
{
  "header": "... {{company_name}} ...",
  "footer": "... подписи ..."
}
```

На следующих шагах добавим редактор блоков и экран настроек путей, чтобы можно было править это внутри приложения без ручного редактирования JSON.
