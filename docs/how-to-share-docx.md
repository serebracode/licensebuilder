# Как передать структуру договоров, если нельзя загрузить `.docx`

Если интерфейс не позволяет прикрепить `.docx`, есть 4 рабочих варианта.

## Вариант 1 (самый простой): экспорт в `.txt`

На macOS:

```bash
textutil -convert txt "/path/to/contract.docx" -output "/path/to/contract.txt"
```

После этого откройте `contract.txt` и вставьте текст сюда сообщением.

---

## Вариант 2: экспорт в `.html`

```bash
textutil -convert html "/path/to/contract.docx" -output "/path/to/contract.html"
```

Подходит, если нужно сохранить абзацы/заголовки и понять структуру блока точнее.

---

## Вариант 3: вручную прислать структуру по шаблону

Скопируйте и заполните:

```md
# HEADER
(верхняя часть договора)

# BLOCKS
## block_id: web
title: Веб-лицензия
description: Использование на сайтах через CSS
body: ... текст с переменными {{domain}} ...

## block_id: desktop
title: Desktop-лицензия
description: Установка на рабочие станции
body: ... {{workstations_count}} ...

# FOOTER
(нижняя часть договора)
```

---

## Вариант 4: если есть только PDF-версия

Можно извлечь текст и отправить его:

```bash
pdftotext "/path/to/contract.pdf" "/path/to/contract.txt"
```

(если `pdftotext` не установлен — достаточно открыть PDF и вручную скопировать текст)

---

## Что прислать в идеале

1. 1–2 примера договоров (текстом).
2. Где заканчивается `header`, где начинается `footer`.
3. Какие фрагменты повторяются как отдельные блоки.
4. Какие значения меняются между договорами (это будущие `{{variables}}`).

После этого я сразу превращу ваши реальные документы в рабочую схему `frame + blocks`.
